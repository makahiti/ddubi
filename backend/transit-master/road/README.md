# 도로 대응표 상태

현재 배포 가능한 운영 artifact는 없다(`manifest.json`: REVIEW_REQUIRED).
검토 후보와 원본은 `data/road-impact-20260911/`에 보존하며 저장소에 포함하지 않는다.
미검증 후보를 공통 운영 마스터로 승격하지 않는다. 검증 후 이 폴더에 artifact를 추가하고
버스 master 버전·SHA, 출처·유효기간을 manifest의 호환 조합에 기록한다.
검증 범위는 [도로 영향 계약](../../../docs/contracts/road-impact.md)을 따른다.

# 정적 시간표-실시간 열차 Crosswalk 계약

## 목적

정적 시간표의 한 운행과 서울 실시간 API의 열차 ID가 같은 열차인지 검증한다. 문자열이
비슷하다는 이유로 연결하지 않는다. 노선·역 순서·시각 일관성과 도착/위치 양쪽 원문 식별값을
확인하고 후보가 하나일 때만 `EXACT`로 승인한다.

Crosswalk는 사고 공지를 경로 구간에 연결하는 계약이 아니다. 사고·운행 변경은 별도의
노선·역·구간 매핑과 알림 Snapshot으로 처리한다.

## 입력 관측

형식은 `subway-train-observations.schema.json`이다. `matchedAt`은 열차가 해당 역에 있었다고
판단한 절대시각이다. 도착 이벤트는 원본 생성시각과 `arrivalSeconds`로 계산한 예상 역 도착시각,
위치 이벤트는 원천 상태 코드를 검증해 선택한 역 시각을 넣는다. 수집시각을 대신 쓰지 않는다.

`export_train_observations.py`는 Archiver의 `transport.raw` 원본을 이 형식으로 변환한다. 현재 서울
위치 API는 역 도착을 뜻하는 `trainSttus=1`만 위치 증거로 허용한다. 진입·출발 상태나 제공시각 없이
수신시각으로 대체된 이벤트는 정확한 역 시각을 증명하지 못하므로 제외한다. 운행일 경계는 당일
00:00부터 다음날 06:00까지이며, 중복 eventId는 제거하고 내용이 충돌하는 ID는 전체 제외한다.
상태 코드 의미는 서울 열린데이터광장의 `realtimePosition` 공식 출력 명세를 기준으로 한다.

각 열차 그룹은 도착과 위치 이벤트가 모두 있어야 하고, 최소 3개 서로 다른 역이 필요하다.
도착/위치별 방향·행선지와 도착 이벤트의 열차 종류는 그룹 안에서 하나로 일치해야 한다.

## 판정

- `EXACT`: 모든 조건을 통과한 정적 운행 후보가 정확히 하나다.
- `AMBIGUOUS`: 조건을 통과한 후보가 둘 이상이다. Backend에 적용하지 않는다.
- `UNMAPPED`: 증거가 부족하거나 일치 후보가 없다. Backend에 적용하지 않는다.

기본 시각 조건은 예정시각과 관측시각의 절대 차이 1,800초 이하, 여러 역에서 계산한 공통
시각 이동량과의 최대 편차 120초 이하다. 기준은 artifact의 `criteria`에 기록한다.

## 출력과 적용

Crosswalk 형식은 `subway-train-crosswalk.schema.json`이다. 원본 증거 SHA-256, 시간표·마스터
버전, 운행일, 판정 근거 이벤트 ID와 후보 목록을 포함한다. 시간표 빌더는 같은 시간표 버전과
운행일을 대상으로 한 `EXACT` 항목만 적용한다. 한 실시간 열차가 두 운행에 연결되거나 한 운행에
두 실시간 열차가 연결되면 전체 적용을 실패시킨다.

다른 날짜의 열차번호 재사용을 막기 위해 산출물은 운행일 00:00부터 다음날 06:00까지만 유효하다.
사람이 근거를 재검토할 수 있도록 Crosswalk와 `.report.json`은 함께 보존한다.

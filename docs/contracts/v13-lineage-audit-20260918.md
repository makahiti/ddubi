## 남은 범위와 재생성 판단

전체 원본 재검사는 모든 원본 파일 형식(CSV/ZIP/Excel), 기간이 월을 넘는 주간 파일,
헤더 복원·원본 격리 행을 명시적으로 연결한 뒤 수행해야 한다. 현재 자동 검사기는 전체 하류
파일 검사와 선택 월의 ZIP 표본에 대한 도구이며, 전체 원본 지원 도구로 과장하지 않는다.

현재 영향받은 날짜/행/특성: **확인된 불일치 없음**. 따라서 현 산출물은 보존하고 재학습하지 않는다.
향후 실제 0 포함 또는 키/정답 불일치가 확인되면 해당 원본 날짜의 정규화·중복 처리·표본/특성을
재생성하고, v13은 학습 분할과 최종 평가를 다시 수행해야 한다. 잘못된 정답을 결과 모델에서
부분 패치하지 않는다. 이번 작업에서 재생성·배포는 수행하지 않았다.

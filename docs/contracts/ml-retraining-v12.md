## 비교와 선택 기준

1. 원본 CSV/Excel을 청크 변환하고 오류 행과 실패 소스를 별도 보고한다. 범용 Parquet 변환을 의미 검증 완료로 부르지 않는다.
2. 버스 시간대별 평균 운행시간을 날짜·노선·인접 정류장·순번으로 검증한다. 0초는 관측 부재로 분리한다. 상충 중복은 격리하고 1,800초 이상 값을 임의 삭제하지 않는다.
3. 날짜 순서로 약 70% 학습 / 30% 테스트를 분리한다. 모델 비교 때만 학습 구간 뒤 20%를 내부 검증으로 사용한다. 최종 학습에서는 내부 검증을 다시 합쳐 70% 전체를 사용한다. 날짜 경계이므로 실제 행 비율은 `split_dates.json`에 함께 기록한다.
4. 전체 기간에서 정답값과 독립적인 고정 표본으로 약 1억 행의 특성을 준비한다. 각 후보는 동일 최대 500만 행과 동일 최대 100만 행의 검증 자료로 비교한다.
5. CatBoost GPU 깊이 6/8, LightGBM, ExtraTrees 및 과거 중앙값 기준선을 비교한다. 후보 2개 이상의 ML 학습이 성공해야 선택한다.
6. 검증 MAE로 한 모델과 트리 수를 고정하고 학습용 70% 전체로 재학습한다. 기존 5천만 행 제한은 제거했다. 디스크 기반 인코딩 배열로 원본 문자열 전량 적재를 피한다. 최종 학습에 합친 내부 검증을 재평가나 조기종료에 사용하지 않으며 테스트는 오직 최종 평가에 쓴다. 기준선이 이기면 전체 학습 구간에서 fallback 통계를 계산하고 이를 숨기지 않는다.
7. 선택에 쓰지 않은 테스트 기간에서 MAE, RMSE, P95 절대오차, 평균 편향, 20초 이내 비율을 보고한다. 비교 그래프와 일별 예측 Parquet도 저장한다.

## 학습·추론 공통 처리와 한계

- 같은 ID 인코더, 학습 집합 중앙값, 명시적 결측 표시를 학습·추론에 재사용한다. 전량 결측 특성은 양쪽에서 제외한다. 신규 ID와 결측 수를 추론 결과에 기록한다.
- 직선거리는 제외한다. 좌표는 검증된 정류장 ID와 기준일 이하 마스터만 연결한다. 요일·주말·한국 공휴일을 날짜에서 생성한다.
- 과거 운행·구간 승객수·승차·운행횟수 이력은 77일 이상 지연시켜 연결한다. 월 파일의 과거 공개·수정 이력이 완전히 복원되지 않아 이 보수적 지연도 무누출을 보장하지 않는다.
- 공개일이 확인되지 않은 월 수요는 모델 연결에서 제외한다. 과거 날씨 재분석을 당시 이용 가능한 예보처럼 넣지 않는다.
- 날씨 가용시각, 도로·유동인구·이벤트 매핑이 검증되지 않은 항목은 정규화·원본 보존과 모델 입력 적용을 구분해 `source_usage.json`에 기록한다.
- 버스 대기·지하철 대기/이동·환승의 검증된 실제 정답이 없으면 가짜 라벨로 학습하지 않는다. 도보는 경로 API 시간 fallback이라는 결정을 유지한다.
- 버스 정답은 **시간대별 인접 구간 평균 소요시간**이다. 개별 차량이나 전체 이용 경로의 실측 오차로 해석하면 안 된다.
- 이전 실험에서 사용한 과거 기간과 겹칠 수 있어 완전히 미관측 미래 성능이라고 주장하지 않는다. 최종 bundle은 `production_ready=false`이며 실서비스 적용 전에 입력 갱신·매핑·미래 평가가 필요하다.

## 자원·검증

- 물리 GPU device 0만 허용. CatBoost GPU 모델에 사용하며 CPU 후보는 CPU에서 학습한다.
- CPU affinity 최대16. 원천 작업 worker8, 일별 조인 worker4로 동시 메모리를 제한한다.
- 자신의 작업 트리 RSS 96GiB 초과, 서버 여유 메모리 128GiB 미만, 디스크 여유 100GiB 미만이면 자기 작업만 중단한다. 서버 장애가 절대 없다는 보장은 아니다.
- 서버 단위시험 13개 통과, 버스 ZIP 내부 CSV 243개 헤더 검증 통과.
- CatBoost 2종·LightGBM·ExtraTrees 소규모 학습/예측 시험 통과.
- 합성 데이터 전체 흐름 및 추론 시험 통과. **합성 시험 결과는 실제 성능 결과가 아니다.**
- 전체 데이터 재정규화와 실제 대량 학습은 별도 장기 실행이며 위 시험 통과가 전체 실행 완료를 의미하지 않는다.

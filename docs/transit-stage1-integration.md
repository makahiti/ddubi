# 교통 데이터 1단계 통합

## 범위
세 파트의 도구·첫 실행·누락 원인 분류를 기존 `feature/frontend/S15P21E202-46-fe-infra-correction`에 통합한다. 전체 자료 생성·적재는 2단계, BE/FE/서버 연결은 3단계다. 데이터 부족을 없애기 위해 임의의 ID·날씨·유효일을 생성하지 않는다. 지역이나 기능은 제외하지 않는다.

## 재현 가능한 테스트
`infra/scripts/check-local-transit.ps1 -Python <실행파일> -RoadDependencies <전용의존성폴더>`

도로 의존성은 road-requirements.txt에 버전을 고정했다. 검증 시 parallel-road/.road-deps를 사용했으며 라이브러리를 제품 저장소나 전역 환경에 복사하지 않았다. 실패한 테스트 그룹은 스크립트를 즉시 실패시킨다.

## 운영과의 구분
본 단계의 정확/연속 후보는 자료 간 구조 일치이지 운영 승인이 아니다. 실제 마스터 유효일, provider 의미, 실시간 출처 연결은 개별 근거와 함께 다음 단계 입력으로 넘긴다. 서버·DB·develop 변경 및 릴리스 배포 없음.
